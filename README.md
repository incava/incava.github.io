# Prompt Crafter

`incava.github.io`에 올릴 프롬프트 생성기 사이트의 초기 MVP입니다.

## 구조

- `index.html`: 메인 페이지
- `styles.css`: 전체 스타일
- `main.js`: 프롬프트 생성, 복사, 브라우저 저장 로직

## 배포 방식

이 프로젝트는 정적 파일만 사용하므로, `incava.github.io` 저장소 루트에 그대로 올리면 GitHub Pages에서 바로 서비스할 수 있습니다.

## 현재 포함 기능

- 프롬프트 카테고리 선택
- 한국어/영어 출력 전환
- 목적, 톤, 대상, 조건, 참고정보 입력
- 프롬프트 미리보기 생성
- 클립보드 복사
- `localStorage` 기반 입력값 유지
